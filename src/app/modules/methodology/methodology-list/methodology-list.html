1. What's live vs. template in this build

LIVE Overview, Payable Summary and Location Bifurcation — every number is computed directly from {{ sourceFileName }} plus the real Consultants table under Interns & Contractors.

SAMPLE Join & Exit, and the Interns portion of Interns & Contractors — illustrative numbers only, because the source sheet has no employee-level join/exit/intern records. Both pages list the exact fields needed to go live.

2. Recommended data model

Keep the Payable Summary as-is for Finance, but add a second employee-level monthly export: Employee ID, Business Unit (matching Payable Summary naming exactly), Department, Designation, Employment Type (Permanent / Contractor / Intern), Date of Joining, Date of Leaving, Exit Reason. That single file unlocks Join/Exit, Interns and designation-level cuts all at once — and can be aggregated to cross-check the existing summary sheet.

3. This build vs. the earlier Gemini mockup — what changed

  • Every KPI, chart and table under Overview / Payable Summary / Bifurcation now uses your actual uploaded numbers — the Gemini version's headcounts and ₹ figures were illustrative placeholders, not derived from your file.
  • Kept the Gemini app-shell UX: collapsible sidebar, top filter bar, CSV export, quick-filter badges — genuinely nice interaction patterns.
  • Replaced the fake 3-month period dropdown with an honest single-period badge — we only have one month of data; a selector implying 3 months would mislead.
  • Split "Contractors" correctly: your source data treats Consultants as its own group (not a sub-slice of HYD/MUM headcount), so the location filter is HYD / MUM / Consultants, and the real Consultants table now lives under Interns & Contractors.
  • Every sample-data section is badge-labeled SAMPLE so nobody mistakes a mockup number for a real one — the Gemini version didn't distinguish real vs illustrative data anywhere.
  • Business-unit level detail (45 rows, sortable, searchable, exportable) replaces Gemini's 6-row mock monthly table — the actual granularity Finance/HR will want to drill into.

4. Known data caveat

Consultant rows don't split Total Net Payable into Actual Gross and Deductions — so those two KPIs are Hyderabad + Mumbai only everywhere on this dashboard (manpower, net payable and CTC all include consultants). Add that split at source if Finance needs a true all-in gross/deductions figure.
